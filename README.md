# void-min

Минимальный Void Linux одним скриптом: ядро, Wi-Fi, терминал и mango, и ничего сверх того.
Пользователь `Bivel`, машина `void`. Поверх ставится [kombain](https://github.com/FalconBinary/kombain)
как есть.

Что получается после установки:

- **Диск**: 1 ГиБ под `/boot` (EFI) и всё остальное под `/` на XFS с `noatime`. Без LVM и без
  раздела подкачки: подкачка в zram со сжатием zstd.
- **Загрузка**: Limine, initramfs только с драйверами этой машины (десятки мегабайт вместо сотен),
  ядро Void с параметрами `preempt=full`, `nowatchdog`, `zswap.enabled=0`. Lockdown и `debugfs=off`
  не ставятся: первое не даёт загрузить модули NVIDIA, второе нужно zcool для EC на MSI.
  32-битные программы запускаются, Steam тоже.
- **Сервисы**: `udevd`, `dbus`, `elogind`, `iwd`, `chronyd`, `zramen`, еженедельный `fstrim` и два
  текстовых терминала. С кабелем добавляется `dhcpcd` для его интерфейса, без кабеля `dhcpcd`
  удаляется: адрес для Wi-Fi получает сам iwd.
- **Драйверы** определяются по железу: микрокод Intel, Mesa для Intel и AMD, для NVIDIA `nvidia`
  (GTX 16xx, RTX 20xx и новее) или `nvidia580` (Maxwell, Pascal, Volta).
- **Убрано** из `base-system`: `wpa_supplicant`, `sudo` (вместо него `doas`), `btrfs-progs`,
  `f2fs-tools`.
- **Пакетов ровно столько, сколько нужно**, подробнее в разделе «Что не ставится и почему».
- **Wi-Fi переносится**: сеть, к которой live-система подключена через `wpa_supplicant`,
  сохраняется для iwd, и после перезагрузки машина подключается сама.

## Установка

Нужен образ **base x86_64 glibc** с `https://repo-default.voidlinux.org/live/current/`, загруженный
в режиме UEFI. Вход: `root` / `voidlinux`.

По кабелю сеть поднимется сама. Для Wi-Fi:

```sh
wpa_passphrase "СЕТЬ" "ПАРОЛЬ" >> /etc/wpa_supplicant/wpa_supplicant.conf
sv restart wpa_supplicant
sv restart dhcpcd
```

Затем:

```sh
xbps-fetch https://raw.githubusercontent.com/FalconBinary/void-min/main/install.sh
sh install.sh
```

Скрипт спросит диск (занятые и флешка с ISO в списке не показываются) и часовой пояс, покажет
план и попросит набрать имя диска. **До этого ничего не меняется, после этого диск стирается
целиком.** В конце `passwd` спросит два пароля, для `root` и для `Bivel`: скрипт их не видит.

Вопросы на английском: в консоли live ISO нет кириллического шрифта.

`sh install.sh --dry-run` задаёт те же вопросы и печатает все команды, ничего не меняя.

## После перезагрузки

Имя пользователя набирается как написано, с заглавной буквы: `Bivel`. Имена в Linux
чувствительны к регистру.

```sh
dbus-run-session mango
```

`Alt+Return` открывает терминал, `Super+m` завершает сеанс. Если Wi-Fi не был перенесён:
`iwctl station wlan0 connect "СЕТЬ"`.

kombain поверх:

```sh
doas xbps-install -S git
git clone https://github.com/FalconBinary/kombain
cd kombain
doas ./install.sh --user Bivel
```

Он добавит sysctl, файрвол, звук, zcool, ztune, netline и свой конфиг mango. Если позже поставите
ядро kombain, хук меню менять не нужно: ядро с дефисом в версии он ставит после стоковых.

## Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `--disk /dev/nvme0n1` | спросит | диск, который будет стёрт |
| `--user ИМЯ` | `Bivel` | пользователь, в группах `wheel`, `audio`, `video` |
| `--host ИМЯ` | `void` | имя машины |
| `--timezone Europe/Kyiv` | спросит, Enter даёт UTC | часовой пояс |
| `--mirror URL` | `https://repo-de.voidlinux.org` | зеркало Void, сейчас и для обновлений |
| `--serial` | нет | консоль и вход ещё и на первом последовательном порту |
| `--dry-run` | нет | показать команды, ничего не менять |

## Что не ставится и почему

Набор посчитан по индексу пакетов Void, размеры после установки:

| Что | Сколько | Почему не нужно |
|---|---|---|
| Прошивки коммутаторов и серверных сетевых карт (Mellanox, Marvell Prestera, QLogic, Chelsio и другие) | 195 МиБ из 440 в `linux-firmware-network` | такого железа нет ни в ноутбуке, ни в настольном ПК; семейство остаётся, если устройство его производителя есть на шине PCI |
| `git` и `perl`, который он тянет | 130 МиБ | для старта не нужны; `git` ставится одной командой перед kombain |
| `linux-firmware-nvidia` | 106 МиБ | это прошивки для nouveau; драйвер NVIDIA приносит свои. Остаётся только для старых карт, которые ведёт Mesa |
| Библиотеки окна настроек NVIDIA и с ними GTK 2 и 3, значки, CUPS, Avahi | 32 пакета, 87 МиБ | `nvidia-settings` работает под X11, в mango его не показать |
| `linux-firmware-amd`, `-intel`, `-broadcom` | 12–32 МиБ каждый | только если в машине нет ни процессора, ни устройств этого производителя |
| Репозиторий несвободных пакетов | один файл | подключается, только когда нужен: микрокод Intel или драйвер NVIDIA |

Прошивки Wi-Fi, Bluetooth и Ethernet для обычных ПК остаются все: адаптер, вставленный позже,
должен заработать. Вернуть серверные: удалить `/etc/xbps.d/21-firmware.conf` и выполнить
`xbps-install -f linux-firmware-network`.

Что остаётся большим и убрать нельзя: ядро с модулями (180 МиБ), LLVM, без которого Mesa в Void
не собирается (140 МиБ), и сам драйвер NVIDIA. С ним приходят `gcc` и заголовки ядра для сборки
модуля, вместе около 1.1 ГиБ: это цена работающей GTX.

Пакеты Void собраны под любой x86_64, вариантов «под этот процессор» в репозитории нет. Скорость
здесь берётся не из пакетов, а из того, чего нет в памяти и при загрузке: десять сервисов,
initramfs под машину, zram, ядро с полным вытеснением. Ядро, собранное под процессор, даёт
kombain, и его выигрыш там измеряется, а не обещается.

## Чего здесь нет

- **Шифрования диска.** Это быстрее и проще, но любой, у кого ноутбук в руках, читает диск.
  Шифрование с двумя режимами есть в `setup.sh` из kombain.
- **Второго пользователя и второго режима.** Игры запускаются тем же пользователем.
- **Звука, файрвола, настроек sysctl, Steam.** Первые три ставит `install.sh` из kombain, Steam
  ставится отдельно.
- **Отключения защит процессора.** `mitigations=off` даёт несколько процентов скорости ценой
  безопасности; если нужно, допишите в строку `CMD=` в `/etc/kernel.d/post-install/60-limine` и
  запустите этот файл.

## Проверки

GitHub Actions на каждый коммит:

- `shellcheck`, разбор скрипта в dash и bash;
- [tests/unit.sh](tests/unit.sh): решения скрипта на выдуманных машинах (GF63 с GTX 1650, настольный
  Ryzen, старые NVIDIA, VM): драйверы, прошивки, сеть, перенос Wi-Fi, порядок ядер в меню;
- [tests/vm.py](tests/vm.py): полная установка с официального ISO в QEMU, с ответами как у человека,
  включая неверные, затем загрузка установленной системы и проверка того, что написано выше.

На настоящем железе скрипт пока не запускался: драйвер NVIDIA и Wi-Fi в виртуальной машине
проверить нечем.
